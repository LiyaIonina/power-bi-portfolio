# Power BI Portfolio

Power BI dashboards built during my data analytics training and practice projects: data modeling, DAX measures, Power Query and interactive reporting.

| Project | Description | Key skills |
|---|---|---|
| [Wildberries Sales Report](wildberries-sales-report/) | 4-page marketplace report: KPIs, SKU details, order heatmap by day and hour, sales by region | PostgreSQL connection, star schema, DAX measures, heatmap |
| [Sales Analytics (DataSfera)](sales-analytics-datasfera/) | Sales dashboard with KPIs, ABC analysis, customer segments and loss-making orders by manager | Data modeling, ABC analysis, field parameters, map visual |
| [Wildberries Finance](wildberries-finance/) | Financial dashboard for a marketplace seller: profit structure, revenue and ROI, growth and decline leaders | Power Query (Google Sheets via `Excel.Workbook`), waterfall chart, DAX |

**Tools:** Power BI Desktop, DAX, Power Query (M), PostgreSQL, Google Sheets

Each folder contains a README with the task, data model, key metrics and screenshots of the report pages.
